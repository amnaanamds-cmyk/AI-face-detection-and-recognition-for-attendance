Use the system on Android phones, iPhones and tablets: {{ t.staffs|lower }} take attendance with the phone camera, {{ t.people|lower }} check their own attendance. The app installs from the browser, with no app store needed.

Android (Chrome)
    {% if has_ca %}
  1. Trust the server (once per phone): download the certificate, then open Settings → Security → More security settings → Encryption & credentials → Install a certificate → CA certificate and choose attendance-ca.crt. On some phones the path is Settings → Security → Install from storage.
    2. {% endif %}
  2. Open the address above in Chrome and log in.
  3. Tap Install app (top bar) or Chrome menu ⋮ → Install app / Add to Home screen.
  4. Open Attendance from the home screen. It runs full-screen like a normal app.
iPhone / iPad (Safari)
    {% if has_ca %}
  1. Trust the server (once per device): open this page in Safari, download the certificate and tap Allow. Then go to Settings → Profile Downloaded → Install, and after that Settings → General → About → Certificate Trust Settings and switch it on.
    2. {% endif %}
  2. Open the address above in Safari and log in.
  3. Tap Share → Add to Home Screen.
  4. Open Attendance from the home screen.
Using the app
  • {{ t.staff }}: Attendance → Create {{ t.session|lower }} → Create & start → choose Back camera → point the phone at the class. On a stand or tripod, 2 frames per second, 720p.
  • Face registration on a phone: {{ t.people }} → {{ t.person|lower }} → Register face → Flip to choose the camera.
  • {{ t.person }}: log in with the {{ t.person_id }} to see attendance percentage, history and warnings.
  • If you skip the certificate step, the browser shows a security warning. Tap Advanced → Proceed; the camera still works, but the app cannot be installed and each visit shows the warning again.
