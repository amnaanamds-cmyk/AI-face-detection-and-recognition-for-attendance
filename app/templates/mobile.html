{{ app_name }} Android app (recommended)
  1. Install it: {% if apk %}download the app or {% endif %}the newest version. If Android asks, allow installing apps from this source.
  2. Open {{ app_name }} and tap Scan QR code (the QR code above), or Choose QR picture from gallery if it was sent to the phone. Or open the link in Chrome and tap Open in the FaceAttend app on the login page.
  3. Log in with your own account. The app remembers the address and reconnects by itself.
The app can also send the parent absence SMS from the phone's SIM card (Admin > Parent messages).
iPhone / iPad, or Android without the app
  1. Open the address above in Safari (iPhone) or Chrome (Android) and log in.
  2. iPhone: Share → Add to Home Screen. Android: menu ⋮ → Install app.
  3. Open {{ app_name }} from the home screen. It runs full-screen like a normal app.
Using the app
  • {{ t.staff }}: Home → My periods today → Start, or Attendance → Start attendance → point the back camera at the class (on a stand or tripod works best).
  • Face registration on a phone: {{ t.people }} → {{ t.person|lower }} → Register face → Flip to choose the camera.
  • {{ t.person }}: log in to see attendance percentage, history and warnings.
