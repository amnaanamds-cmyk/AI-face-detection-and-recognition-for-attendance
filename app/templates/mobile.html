Using the app
  • {{ t.staff }}: Attendance → Create {{ t.session|lower }} → Create & start → choose Back camera → point the phone at the class. On a stand or tripod at 720p.
  • Face registration on a phone: {{ t.people }} → {{ t.person|lower }} → Register face → Flip to choose the camera.
  • {{ t.person }}: log in with the {{ t.person_id }} to see attendance percentage, history and warnings.
  • If you skip the certificate step, the browser shows a security warning. Tap Advanced → Proceed; the camera still works, but the app cannot be installed and each visit shows the warning again.
