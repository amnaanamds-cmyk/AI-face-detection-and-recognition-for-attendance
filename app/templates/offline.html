The app is only a window onto the attendance server, so the server has to be running first.

  1. On the server PC, start the server: double-click start.bat (or start-mobile.bat if you use phones). Keep its black window open.
  2. Wait until the window says the server is running (about 10 seconds).
  3. On a phone or tablet, connect to the same Wi-Fi as the server PC.
